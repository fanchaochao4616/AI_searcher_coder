## 网页搜索
如果我想知道“广州大学最近发生了什么”：
```web_search
2025年3月广州大学发生了什么
```

## 航班查询

如果我需要了解航班状态：“A225航班怎么样”：
```flight_search

```

## 文件操作

查找文件：
```file_finder

```

读取文件：
```file_finder:read
toto.py
```
